# Основания и фундаменты

Настольная программа для расчёта фундаментов мелкого заложения по приложенной редакции СП 22.13330.2016 и учебной методике лекций №5–6. Расчётное ядро не зависит от Qt. Свайный модуль предусмотрен в дереве интерфейса как следующее направление разработки.

## Запуск из исходников

Для ежедневной работы на macOS используются команды из корня проекта:

```bash
make run       # быстрый запуск исходников
make check     # модульные тесты и UI smoke-test
make build     # сборка dist/OIF-Foundations.app
make install   # проверка, сборка и установка в ~/Applications
make open      # запуск установленного приложения
```

Перед `make install` закройте ранее запущенный OIF-Foundations. Установленный файл имеет постоянный путь `~/Applications/OIF-Foundations.app`, поэтому его можно один раз добавить в Dock.

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -e '.[desktop]'
.venv/bin/oif-desktop
```

В Windows последняя команда: `.venv\Scripts\oif-desktop.exe`. Для тестов: `.venv/bin/python -m unittest discover -s tests -v` (в Windows используйте `Scripts\python.exe`). Личный SQLite-справочник хранится в системном каталоге данных пользователя. Переменная `OIF_DATA_DIR` задаёт альтернативный каталог.

Сборки для Windows, Linux и macOS создаёт GitHub Actions. После завершения workflow их можно скачать из раздела `Artifacts`. Сборка прошла локальную проверку запуска на macOS arm64; пакеты для Windows и Linux пока требуют отдельной проверки на целевых системах.

## Реализовано

- Выбор учебного `Hc` по `0,2σzg` и варианта с критерием СП `0,5σzg`. В обоих вариантах осадка вычисляется по формуле лекции `s=Σ0,8σzp,i hi/Ei`; `Ee_i` не применяется.
- Предварительный подбор по `R0`: таблица Б.2 для песков, таблица Б.3 для глинистых грунтов с автоматическим расчётом `e`, `Ip`, `IL`. Площадь определяется по `A=N/(R0−γмd)`, размеры округляются вверх до 0,1 м. Для ленточного фундамента расчётная длина фиксирована: `l=1 м`.
- Таблицы Б.2–Б.3 и логика выбора `R0` доступны в отдельном разделе «Справочники → Таблицы R₀»; из экрана предварительного подбора к ним ведёт отдельная кнопка.
- Окончательный расчёт `R` по формуле (5.7), коэффициенты табл. 5.4–5.5, давление, эксцентриситет и диагностический флаг `pкрай≤1,2R`. Для подвала `d1` рассчитывается по формуле (5.8), а `db` ограничивается 2 м.
- Проверка эксцентриситета ведётся по `e≤l/6` для столбчатого и по `e≤b/6` для ленточного фундамента. Автоподбор увеличивает подошву с шагом площади `0,1 м²` до выполнения обоих условий: без отрыва и `p≤R`.
- Послойный расчёт осадки с интерполяцией α, границами ИГЭ/УГВ и явно выбранным способом определения `Hc`; особое правило слабого слоя проверяет `E≤7 МПа`.
- Выбор фундаментов на странице схемы с автопереносом нагрузок и типов в исходные параметры; общая глубина заложения и отдельный режим здания с подвалом.
- Геологический разрез можно задавать как глубинами от поверхности (`0→6→12 м`), так и абсолютными отметками (`130→124→118 м`). Абсолютные отметки автоматически преобразуются в глубины, но сохраняются в проекте и отчёте в исходном виде.
- Строки геологических слоёв и фундаментов удаляются крестиком справа. В справочнике грунтов так же можно удалять созданные пользователем записи; встроенные 81 запись защищены от удаления.
- Полные карточки всех грунтов: исходные показатели, `ρd`, `e`, `Sr`, `Ip`, `IL`, `β`, `mv`, природный, сухой и взвешенный удельные веса. Эти данные включаются в Word/Excel-отчёты и PDF/Excel-экспорт справочника.
- SQLite-справочник, личные грунты, переносимый `.oifcatalog`, проект `.oifproj` со снимком каталога и контрольными суммами, несколько расчётов по фундаментам и сочетаниям в одном проекте. В интерфейсе доступны чертежи всех 25 схем из задания.
- Отдельная папка проекта с именем `Объект — Профиль`: в ней хранятся `.oifproj`, Word/Excel-отчёты и экспорты. Родительскую папку можно выбрать через проводник или ввести вручную.
- Коэффициенты перевода единиц хранятся в каждом проекте. Для `тс→кН` можно принять точное `9,80665`, учебное `9,8`/`10` или своё значение; принятые коэффициенты включаются в отчёт.

## Ограничения текущей версии

Встроенный каталог содержит 81 строку грунтов и 25 схем с 516 сочетаниями нагрузок из цифрового текста задания. Заголовки и номера чертежей всех схем сверены визуально. Грунты №29, 40, 81 и схема №18 с её 24 сочетаниями нагрузок сверены визуально; остальные числовые записи помечаются предупреждением до ручной сверки. Для строк с отсутствующим `cII` окончательный расчёт блокируется, без подстановки нуля. Значения `±` в нагрузках сохраняются как в источнике и требуют выбора направления при вводе момента на уровне подошвы. Пользователь может дополнить каталог собственными записями с указанием источника.

Момент на уровне подошвы, расчётный удельный вес грунта ниже подошвы и вес фундамента/засыпки вводятся явно. Для расчёта при УГВ нужны эффективные удельные веса грунтов ниже воды. При наличии подвала требуются глубина пола, толщина грунта над подошвой со стороны подвала, толщина и удельный вес пола; средний вес фундамента и засыпки пользователь задаёт с учётом пустоты подвала. Проверка слабого подстилающего слоя по п. 5.6.25, крен, взаимное влияние фундаментов и предельная осадка по типу здания не входят в данный расчёт. Сборочные пакеты Windows/Linux/macOS заданы в CI, но ещё требуют запуска и проверки на каждой ОС.

Исходные нормативные и учебные файлы не изменялись. Архитектурный анализ, реестр источников и разбор расхождений с исходной Excel-книгой находятся в `analysis/`.
